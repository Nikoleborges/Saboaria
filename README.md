# 🌿 Saboaria das Marias

Um espaço dedicado ao cuidado, ao bem-estar e à beleza natural.

## ✨ Sobre o projeto

A **Saboaria das Marias** é um projeto de desenvolvimento web criado para apresentar os produtos da marca de forma elegante, intuitiva e acolhedora.

O site busca valorizar o universo da saboaria artesanal, proporcionando aos visitantes uma experiência agradável de navegação e uma maneira prática de conhecer os produtos disponíveis.

## 🧼 O que você encontra no site?

- Apresentação da marca;
- Catálogo de produtos artesanais;
- Categorias de sabonetes e produtos para cuidados pessoais;
- Informações sobre os produtos;
- Navegação entre as páginas do site.

## 🎨 Identidade visual

O projeto utiliza uma identidade visual inspirada na natureza, com tons suaves, elementos delicados e uma composição minimalista, buscando transmitir acolhimento, cuidado e autenticidade.

## 💻 Tecnologias utilizadas

- **HTML5** — estrutura das páginas;
- **CSS3** — estilização e identidade visual;
- **JavaScript** — recursos de interatividade.

## 🚀 Como visualizar o projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/Nikoleborges/Saboaria.git
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
